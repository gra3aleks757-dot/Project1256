# Project1256 — DataMatrix генератор растровых штрихкодов

**Project1256** — это консольное приложение на C++, предназначенное для генерации **2D матричных штрихкодов DataMatrix** и сохранения их в виде **растровых изображений (BMP)**. Это один из модулей большого проекта, который в будущем будет объединён с другими частями.

## Возможности

- Генерация символов DataMatrix (кодирование текстовых/байтовых данных)
- Экспорт результата в **BMP** файл (черно-белое растровое изображение)
- Настройка размера модуля (пикселей на ячейку)
- Поддержка различных размеров матрицы (от 10×10 до 144×144)
